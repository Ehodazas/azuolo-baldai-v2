# Ąžuolo baldai — svetainė, 2 versija

Antroji, atskira svetainės versija. Pirmoji versija: https://github.com/Ehodazas/azuolo-baldai

Kryptis: šilti neutralūs tonai, ąžuolas ir grafitas, žurnalo stiliaus kompozicijos. Svetainėje nėra išgalvotų
kainų, atsiliepimų, garantijų ar įmonės faktų. Ko trūksta, surašyta faile [TRUKSTAMA-INFORMACIJA.md](TRUKSTAMA-INFORMACIJA.md).

| Kelias | Paskirtis |
|---|---|
| `index.html` | Vienas pagrindinis puslapis: gaminiai, darbo eiga, mediena ir apdaila, klausimai, užklausa |
| `privatumas.html` | Privatumo politika (juodraštis) |
| `404.html` | Puslapis „Nerasta“ |
| `styles.css` | Visi stiliai |
| `js/app.js` | Meniu, nuotraukų peržiūra, gaminio parinkimas formoje, žemėlapis, socialiniai tinklai |
| `js/catalog.js` | Gaminių kategorijos ir tipai – vienas duomenų šaltinis |
| `js/inquiry.js` | Užklausos krepšelis, įsiminti gaminiai, paieška tarp gaminių |
| `js/forms.js` | Užklausos formos patikra ir siuntimas |
| `config.js` | Formos serverio adresas |
| `api/uzklausa.php` | Užklausų priėmimas ir siuntimas el. paštu |

Formos prijungimas: [INTEGRACIJA.md](INTEGRACIJA.md).
